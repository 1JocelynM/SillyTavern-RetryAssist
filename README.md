# SillyTavern-RetryAssist

SillyTavern 酒馆助手（JS-Slash-Runner）脚本，自动重试过短/空/因网络或者capacity等报错回复

## 功能

- **过短检测**：回复长度低于设定阈值时自动重试
- **断流检测**：完全没收到回复时自动重试
- **两种重试方式**：
  - **Swipe**：在当前消息上生成平行分支，保留历史
  - **删除重开**：单聊用 regenerate（清除所有 swipe），群聊自动识别角色名后删除消息并 `/trigger 角色名`
- **群聊兼容**：自动从失败消息读取角色名，不会跳到别的角色头上
- **手动暂停保护**：用户手动停止生成后不会误触发重试

## 安装

1. 安装 [酒馆助手（JS-Slash-Runner）](https://github.com/N0VI028/JS-Slash-Runner) 扩展
2. 下载 `自动重试助手v2.json`
3. 在酒馆助手的脚本库中导入该 JSON 文件

## 设置

点击脚本按钮 **⚙️ 设置** 可配置：

| 选项 | 默认值 | 说明 |
|------|--------|------|
| 最大重试次数 | 100 | 连续失败超过此次数停止 |
| 最小回复长度 | 50 字符 | 低于此长度触发重试，设为 0 禁用 |
| 重试延迟 | 300ms | 每次重试前的等待时间 |
| 重试方式 | Swipe | Swipe 或 删除重开 |
